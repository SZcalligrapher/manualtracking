# Manual Tracking Editor

一个为“手指框选 + 动态蒙版”视频设计的本地 Web 剪辑工具。它会在浏览器里识别双手关键点，允许逐帧修正指尖位置，并把图片或视频合成到手指围出的区域内或区域外。

不需要 Electron、后端服务器或账号。视频、轨迹和工程数据默认留在本机。

> 项目仍处于早期阶段，适合实验、二次开发和制作手势蒙版类短视频。欢迎提交 Issue 和 Pull Request。

## 功能

- 使用离线 MediaPipe Hand Landmarker 识别双手 21 个关键点。
- 支持拇指、食指、中指、无名指和小指，共 10 个稳定指尖 ID。
- 支持 5、10、15、30 fps 采样；可重识别全片或只查找当前帧。
- 可按时间段指定“生效手指”，自动删除未选手指，并补齐区间内漏检点。
- 可在时间轴创建、拖动和缩放手动修正区间，逐帧拖拽指尖位置。
- 提供小位移平滑，降低相邻帧抖动，同时保留大动作和手动锚点。
- 使用固定手指拓扑连接蒙版；翻手时可形成交叉三角，不会被凸包强制包成矩形。
- 蒙版支持“内部”和“反选（外部）”两种模式。
- 上层素材轨支持多个图片/视频 Clip，可拖动、修剪、分割、换序和删除。
- 内置故障闪切、RGB 分离、霓虹扫描、反馈残影等 9 种 Canvas 特效。
- 预览直接播放原视频音轨；导出时隐藏编辑圆点与标签，只保留实线蒙版边框。
- 支持 `.mtrack.json` 工程导入/导出，以及浏览器本机保存和恢复。
- 浏览器支持 H.264 时导出 MP4，否则自动降级为 WebM。

## 快速开始

推荐使用最新版 Chrome。项目是纯静态页面，只需要一个本地 HTTP 服务。

```bash
git clone https://github.com/SZcalligrapher/manual-tracking-editor.git
cd manual-tracking-editor
python3 -m http.server 8321
```

然后打开 [http://localhost:8321](http://localhost:8321)。请不要直接双击 `index.html`，浏览器需要通过 HTTP 地址加载本地模型和 WASM 文件。

## 基本工作流

1. 点击“打开视频”，选择作为底层画面的原视频。
2. 点击“首次识别全片”，选择采样帧率并等待分析完成。
3. 在时间轴设置各阶段的生效手指；需要时重识别全片或查找当前帧。
4. 创建手动修正区间，在区间内拖动指尖点。区间两端可直接拖拽调整。
5. 添加图片或视频素材，在上层轨道拖动、修剪或分割 Clip。
6. 为每段 Clip 选择蒙版内/蒙版外模式和可选特效。
7. 保存 `.mtrack.json` 工程，或保存到浏览器本机以便下次继续。
8. 点击“导出 MP4”生成预览成片。

## 时间轴与蒙版

编辑器包含两条主要视频轨：

- **外部原视频**：贯穿全片的底层视频，也是默认的识别来源和音频来源。
- **蒙版内素材**：放置图片或视频 Clip。片段可在蒙版内部显示，也可反选后显示在蒙版外部。

同一帧出现重叠 Clip 时，以列表中更靠后的可见 Clip 为准。“查找当前帧位置”也会优先使用当前时间最上层的可见媒体；没有可用上层素材时才回退到原视频。

## 手动修正与工程保存

- 标准手指只能在“手动修正”区间内拖动，避免一次调整意外影响整段轨迹。
- 手动修正区间会按整数帧吸附，并可从左右边缘改变起止帧。
- 小位移平滑只处理自动轨迹；手动锚点、大动作和明显跳点不会被平均掉。
- “保存到本机”会把工程和已关联媒体写入浏览器 IndexedDB。
- `localhost` 与 `127.0.0.1` 是不同的浏览器存储空间，请固定使用同一个地址。
- 工程 JSON 不嵌入大型媒体；跨设备打开工程时，需要重新选择同名素材完成关联。

## 隐私

手部识别、时间轴编辑和预览合成都在浏览器本地执行。项目代码没有上传视频的逻辑。浏览器、第三方运行时或你自行加入的代码可能有各自的隐私行为，公开部署前请自行审查。

## 已知限制

- 当前是单层上轨素材，不支持多层同时混合、转场、变速或完整音频剪辑。
- 蒙版是基于稳定指尖 ID 的固定拓扑，不是带贝塞尔控制柄的通用钢笔工具。
- 手部被遮挡、运动模糊、左右手交叉或画面过暗时，自动识别仍可能需要人工修正。
- 视频按原时长实时录制；切换浏览器标签页或设备性能不足可能造成掉帧。
- MP4/H.264 导出取决于浏览器编码支持；不支持时会生成 WebM。

## 开发与贡献

完整编辑器没有构建步骤，修改后刷新页面即可。`tools/` 中的脚本需要 Node.js，但它们不是运行编辑器的必需条件。

提交 Issue 时，建议提供浏览器版本、视频分辨率/帧率、复现步骤和去除隐私内容后的工程 JSON。请不要上传未经授权的视频素材。
